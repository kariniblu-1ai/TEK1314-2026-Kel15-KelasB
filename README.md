Hello, Welcome to "Kelompok 15"

# Skenario
Proyek ini merancang jaringan pengujian keamananan yang terdiri dari tiga node utama, yaitu Attacker Node, Target Node, dan Monitoring Node.
Attacker Node menggunakan Kali Linux sebagai node penyerang. Target Node menggunakan DVWA sebagai target pengujian keamanan web. Monitoring Node menggunakan Security Onion untuk memantau aktivitas jaringan.

Jaringan menggunakan `192.168.15.0/24` dengan:
> Target Server: 192.168.15.5
> Attacker Node: 192.168.15.100
> Monitoring Node: 192.168.15.200
